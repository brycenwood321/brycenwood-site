The Context

Blackout Auto Tint is a window tinting shop in West Jordan, Utah, run by Mark and Brandon. I walked into their shop to demo what a Custom Business Build looks like — and built their entire website live, in conversation with Claude Code, while they watched.

What Was Built

A complete 7-page website with:

  • Custom design system — not a template. Colors, typography, and layout designed specifically for their brand and auto tint industry
  • Full schema markup — LocalBusiness structured data for Google rich results
  • llms.txt — AI-readable summary so ChatGPT, Claude, and Perplexity can recommend their business
  • Markdown mirrors — clean .md version of every page for AI crawlers
  • Mobile responsive — works perfectly on phone, tablet, and desktop
  • SEO optimized — meta tags, OG images, sitemap, proper heading hierarchy

Why This Matters

This wasn't a production client build — it was a proof of concept. The point was to show that what used to take an agency 4-6 weeks and $5K-$15K can now be done in a single afternoon.

The real Custom Business Build goes deeper — CRM, email automation, dashboards, lead generation, content pipelines. The website is just one piece. But if the website alone can be built in 4 hours, imagine what 2 full weeks produces.

Key Takeaway

"Every client build is custom-researched for their industry. No templates. No copy-paste. If I built Blackout the same way I built Summit Wraps, it wouldn't work — because they're different businesses with different needs."
